# سيرفر إشعارات «اطمئن»

Cloudflare Worker بيحفظ اشتراكات الموبايلات في الإشعارات، وبيبعت إشعار في وقت كل صلاة.

- **الرفع:** من Cloudflare، وبعدين Workers & Pages، وبعدين Create، وبعدين Import a repository، واختاري `itmaen`، والـ Root directory: `push`.
- **الإعداد:** مش محتاج أي حاجة. مفاتيح التشفير بتتعمل لوحدها أول مرة وبتتحفظ جوه السيرفر، وبتشتغل كل دقيقة لوحدها.
